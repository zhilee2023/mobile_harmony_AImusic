² 完整资产ROM按基线清单计：公开20项3,909,445,028字节，小模型18项906,656,016字节，包括输入embedding、条件表、图、tokenizer和辅助表；不含HAP、输出歌曲、日志、运行时KV/激活或保留的其他模型版本。它不是本轮重新扫描手机目录后的磁盘总占用。MiB/GiB是二进制单位，GB是十进制单位。外部weight行只算对应`.weight`文件。此次小模型ONNX新包清单相差24字节；PT重导出公开VAE新包为3.642GiB，但不是这次60秒基线。

³ 全程连接USB，功率为电池端`|V×I|`，不是App、SoC或整机功耗；样本算术均值不是全程时间加权能耗。冷却后起始电池温度31°C，未回到公开模型初始28°C。RSS是共享物理内存中的进程驻留量，不是专用显存。CPU High/Low是计算精度偏好，W4/W8是权重存储目标；请求6线程不等于固定使用6个核心。历史同机工作线程允许列表为CPU2–13，但本轮没有重新采集亲和性和实际核轨迹，不能把历史列表当成本轮绑定结果。
