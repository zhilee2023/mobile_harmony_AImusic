# W4 双投影和直接 SiLU 门控

2026-11-25 真机 CMM-AL00，0.6B 音乐 LLM、CPU High、4 线程、同一固定前缀和教师 token 序列。实验只运行 LLM，输出耗时用于比较相同 513 位置 Prefill 和 64 次 Decode 的工作量。

对 28 层分别合并共享输入的 `up_proj` 与 `gate_proj`。两个 1024→3072 的 W4/group64 投影变为一次 1024→6144 投影。保留压缩码、FP16 量化比例、权重次序及其余参数的偏移。权重文件大小均为 251737602 字节。

| 版本及其对应原版 | Prefill ms | Decode ms/token | 完整 LLM ms | 平均采样峰值 RSS MiB |
|---|---:|---:|---:|---:|
| 切分实验原版 | 2039.45 | 18.040 | 3193.98 | 512.89 |
| 合并投影再切分 | 2204.92 | 19.138 | 3429.76 | 518.34 |
| 直接门控实验原版 | 2109.52 | 18.516 | 3294.55 | 510.27 |
| 合并投影加直接门控 | 2106.71 | 18.503 | 3290.92 | 509.45 |

每组使用原版、候选、候选、原版顺序，每个进程三轮，取后两轮均值后再对两个进程平均。切分组最后一次原版因息屏作废，亮屏后补测，替补结果与其他样本之间有时间间隔。直接门控组四个进程连续通过屏幕控制，电池 30–32°C。

切分候选的 Prefill 出现 56 次额外 Raster，回调合计 180.94 ms。直接门控在打包布局中读取两个 3072 通道的连续半区，调用与原版相同的 MNN SiLU 和乘法内核，剖析记录同一段的额外 Raster 为零。独立候选只支持当前活动的四通道打包和物理 FP32 CPU 布局，使用当前静态归档预留的 Plugin 注册位。

两种实现的固定样本 logits 相对 L2 和最大绝对误差均为零。各直接门控计时进程均命中 5460 次，覆盖 28 层、三轮、每轮 65 次前向。切分版整条 LLM 约慢 7.38%。直接门控约快 0.11%，该差异小于原版进程间波动。当前默认保留原版。现有结果按整条 LLM 工作量测量，因此保持在验证报告中供后续对照，逐部署位置的独立配对延迟仍待测。
